Tilesday Daily

One puzzle a day, the same for everyone. Seven tiles arrive one by one; make Mahjong before they run out.

How it works

  • You start with 13 tiles. Each move, take the next tile and discard one, or declare Mahjong when your 14 tiles make a hand on the card.
  • Every move is graded: green for the best move, yellow for one tile off, red for further. A line says why.
  • One try a day. Puzzles get harder through the week, gentlest on Monday.
  • Every puzzle is proven fair: playing the best move every time always reaches Mahjong.
